# 개인 재무관리 앱 (Personal Finance Manager) - v0.1 요구사항

## 프로젝트 개요
가계부와 주식 투자 일기를 결합한 종합 재무관리 웹 앱
- 고점 대비 하락률 모니터링 기능 포함 (-10% 알림)

## 프로젝트 위치
`/root/Workspace/playground/finance-diary`

## 기술 스택
- **Frontend**: React + TypeScript + Vite
- **UI**: Tailwind CSS (빠른 스타일링)
- **데이터 저장**: Google Sheets API
- **차트**: Recharts (자산 시각화)
- **주가 API**: Yahoo Finance API (무료, 한국 주식 지원)
- **배포**: GitHub Pages (무료, 서버 불필요)

> ⚠️ **서버 없음**: 빌드 후 순수 HTML/CSS/JS 정적 파일만 생성되어 GitHub Pages에서 무료 호스팅. 별도 서버나 바이너리 필요 없음.

## 핵심 기능

### 1. 가계부 (수입/지출)
- 일별 수입/지출 기록
- 카테고리 분류 (식비, 교통, 쇼핑 등)
- 월별 요약 및 통계

### 2. 주식 매매 기록 + 일기
- 매수/매도 내역 기록 (종목, 수량, 가격, 날짜)
- 매매 당시 판단 근거/메모 작성
- 거래 히스토리 조회

### 3. 포트폴리오 현황 + 고점 추적
- 보유 종목 목록
- 평균 매수가, 현재가 (Yahoo Finance API 자동 조회)
- 종목별/전체 수익률
- **고점(High Watermark) 추적**: 보유 기간 중 최고가 기록
- **하락률 알림**: 고점 대비 -10% 도달 시 시각적 경고
- 일별 종가 히스토리 저장

### 4. 대시보드
- 전체 자산 요약
- 이번 달 수입/지출 현황
- 투자 수익률 차트

## 구현 단계

### Phase 1: 프로젝트 설정
1. Vite + React + TypeScript 프로젝트 생성
2. Tailwind CSS 설정
3. 기본 폴더 구조 생성

### Phase 2: Google Sheets 연동
1. Google Cloud Console에서 프로젝트 생성 (사용자 작업)
2. Sheets API 연동 모듈 구현
3. 인증 플로우 구현 (OAuth 또는 API Key)

### Phase 3: 핵심 기능 구현
1. 가계부 CRUD
2. 주식 매매 기록 CRUD
3. 포트폴리오 계산 로직

### Phase 4: 주가 API 연동
1. Yahoo Finance API 연동 (yfinance 또는 직접 호출)
2. 일별 종가 자동 조회 및 저장
3. 고점 추적 로직 구현
4. 하락률 알림 기능 (-10% 경고)

### Phase 5: UI/대시보드
1. 메인 대시보드
2. 각 기능별 페이지
3. 차트 및 시각화

## 참고: 한국 주식 종목코드
- Yahoo Finance에서 한국 주식은 `종목코드.KS` (코스피) 또는 `종목코드.KQ` (코스닥) 형식
- 예: 삼성전자 = `005930.KS`, 카카오 = `035720.KS`

## 검증 방법
1. `npm run dev`로 로컬 실행
2. Google Sheets 연동 테스트
3. 데이터 입력/조회/수정/삭제 테스트
4. 주가 API 조회 테스트
5. 고점 대비 하락률 계산 확인
6. 다른 기기에서 접근하여 데이터 동기화 확인
